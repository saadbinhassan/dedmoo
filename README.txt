SLAO STORE COMPLETE v13 (WITH DATABASE/BACKEND & ALL UPDATES)
==============================================================

1. HOW TO RUN THE BACKEND & DATABASE (For Cross-Device Sync):
   - Open terminal inside the 'SLAO_Store_Complete-v13' folder
   - Run: npm install
   - Run: npm start
   - Open http://localhost:3000 in your browser (and http://localhost:3000/admin-orders.html for Admin Portal).
   - Orders, Reviews, Customer Likes, and Complaints from other devices are saved in 'slao_database.json'.

2. INCLUDED UPDATES:
   - Database / Backend API + Admin Portal tabs for Orders, Customer Product Likes, Product Reviews, and Complaints.
   - 'Add to Cart' button added on every product card across Home & Collections; empty cart displays only a clean empty cart notice.
   - Login / Sign Up page features 'Continue with Google' (with Gmail profile picture), hides Login/Sign Up options after signing in, displays profile picture (with upload option if missing), and includes a pencil icon to edit display name.
   - Privacy Policy (privacy-policy.html) and Terms & Conditions (terms-and-conditions.html) added and linked in footers.
